✨What ahLOOKah does

A floating control panel drives a fullscreen output window in realtime — tweak parameters, morph between effects, key patterns to the number row, and take cues live with zero blank gaps.

🎛️ Audio-reactive library

Beat-driven patterns, cinematic GPU shaders, neon/laser looks, glitch effects, and camera-input video FX.

🪟 Dual-window sync

A fullscreen output window plus a control panel, synchronized over BroadcastChannel — no server state.

⚡ CUE mode

Warm the next program in a hidden renderer with Shift+click, then hit Enter to take it live instantly.

🔀 Dual-effect merge

Blend two sketches with a crossfade or additive composite, layered on the GPU.

🚀Quick start

npm install
npm run dev      # start the dev server

Open the printed URL — a control window launches. Use Open Output to show the fullscreen stage. Audio from your system (or an attached device) drives the visuals.
